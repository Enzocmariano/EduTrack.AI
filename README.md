# EduTrack AI

Projeto acadêmico desenvolvido em colaboração por **Gustavo Paulino Augustin** e **Enzo Cardoso Mariano**. O desenvolvimento contou com apoio de ferramentas de IA, incluindo Codex e Claude Code.

Este repositório contém o pacote completo do projeto em `edutrack-ai-source.zip`. Baixe o arquivo ZIP e extraia seu conteúdo para acessar a estrutura original de desenvolvimento.

- **Aplicação:** https://edutrack-ai-gugaa-2026.netlify.app
- **Repositório original da colaboração:** https://github.com/GustavoAugustin2607/edutrack-ai

O pacote inclui código-fonte, documentação, testes, imagens e configurações. Arquivos locais de ambiente e credenciais não foram incluídos.
